# GitHub profile visual system

## Palette
- Background: `#000000` / `#141414`
- Accent: `#c41212` → `#ff2a2a`
- Text on GitHub: default light

## Formats
| Asset | Size | Role |
|-------|------|------|
| `banner.png` | 1280×400 | Hero |
| `about.png` | 960×720 | About side panel (4:3) |
| `card-*.png` | 640×640 | Direction cards (1:1) |
| `strip.png` | 1280×120 | Section separator |
| `footer.png` | 1280×220 | Closing atmosphere |
| `divider.svg` | 1280×20 | Thin accent line |

## Layout rules
1. One hero image only at the top
2. About = text + 4:3 panel side by side
3. Directions = three equal 1:1 cards
4. Use thin strips between major blocks, not another full banner
5. Footer image only once at the end
6. No stacking of multiple identical 16:9 banners
